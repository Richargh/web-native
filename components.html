Html Components

Html has a lot of great built-in components.

<details>

The <details> element is a disclosure widget which can be expanded to reveal additional content. When closed, only the nested <summary> element is visible.

A long-winded text that is hidden when you click on the summary.

Mutually exclusive <details>

Multiple <details> elements which use the same name attribute are mutually exclusive. When one member of the group is opened, all other members are closed.

Web Components

Web Components can add components to html that are not there yet. You can use the available features to write one yourself, use a community-supplied standalone (see below) or use a web component library:

  • WebAwesome (previously Shoelace)
  • QuietUI

Relative Time

Formats a timestamp as a localized string or as relative text that auto-updates in the user's browser.

The following code:

                
<relative-time datetime="2025-10-23T22:30:00+02:00">
    October 23rd, 2025 10:30pm
</relative-time>

Looks like this in html:

October 23rd, 2025 10:30pm
