This page keeps track of (some) of the possibilities of the modern web. The web is constantly evolving so do not expect every feature to show up here. I try to show the most important ones though.

Webstatus keeps track of which features are available in the common browser out there.

Single-document View Transitions

Aka the view transitions that work with JavaScript and the startViewTransition() method. A longer code-example might look like this: 
                
function handleClick(e) {
    // Fallback for browsers that don't support this API:
    if (!document.startViewTransition) {
    updateTheDOMSomehow();
    return;
    }

    // With a View Transition:
    document.startViewTransition(() => updateTheDOMSomehow());
}

URLPattern

aka the view transitions that work with @view-transition CSS rule sets.

URLPattern Api

A standardized, powerful, and interoperable solution to react to Url changes. A code-example: 
                
const pattern = new URLPattern({ pathname: "/users/:id" });
const isMatch = pattern.test(location.href);
