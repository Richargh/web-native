Overview

This page keeps track of (some) of the possibilities of the modern web. The web is constantly evolving so do not expect every feature to show up here. I try to show the most important ones though.

Webstatus keeps track of which features are available in the common browser out there. Note that this is not necessarily the same as the Can I use queries. WebStatus only tracks the top four browsers (Chrome, Edge, Firefox, Safari). This is ok insofar as there are only these four browser engines. There are initiatives like Ladybird or Servo but these are not common at all. But not all platforms update their browsers as often, some older (mobile) devices even stop getting updates.

So if your site is supposed to be viewed in IE11, on all the iOS/Android devices out there or in a more quirky device, you might refrain from using the newest features or make sure a fallback is available. Quirky devices include:

  • Kindle (uses NetFont a WebKit derivative.
  • An older Playstation. The PlayStation 2, Playstation 3, PlayStation Portable and PlayStation Vita uses NetFont, a WebKit derivative.
  • A newer Playstation. The PlayStation 4 and Playstation 5, uses WebKit and WebKit for which they make the source available.
  • Nintendo device. The 3DS, Wii U, Switch and Switch 2 uses NetFont, a WebKit derivative.
